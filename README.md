# 스타터 포지

`index.html`을 브라우저에서 열면 됩니다. 파일 하나에 코드와 폰트가 포함되어 있어 설치·서버·인터넷 연결이 필요 없습니다.

## 사용

- **새 스타팅 뽑기**: 새 시드로 타입, 종족값, 형태, 특성, 전용기를 생성합니다.
- **시드로 생성**: 같은 시드·규칙 버전·공통 제한으로 결과를 재현합니다.
- **한 단계씩**: 능력치를 하나씩 공개합니다. 기록에서 실제 난수 3개와 조정된 범위를 확인할 수 있습니다.
- **생성 규칙**: 공개된 형태 판정 수식과 27개 기준 분배를 확인합니다.
- **특성·기술 도감**: 특성 116개, 기술 968개 항목, 환경 26개를 검색합니다. ‘창작’ 또는 ‘원작 기반’도 검색할 수 있습니다.
- **실전 설정**: 레벨 50 실능치, 형태별 노력치·성격·아이템 추천과 기술별 결정력을 비교합니다. IV·EV·성격·도구·날씨·필드·조건을 직접 수정할 수 있습니다.
- **JSON 저장**: 생성 결과, 추첨 기록, 판정 근거와 창작 전투 규칙을 저장합니다.

## 생성 콘텐츠 목록 · v1.10.0

창작 필드 생성 특성은 개미굴메이커·옥타곤메이커·페인트메이커·스왐프메이커로 통일했습니다. 창작 날씨 생성 특성은 어스름(어두운 오라)·바람몰이(강풍)·안개장이(조용한 안개)·매캐한숨(독가스)·우레소리(뇌우)입니다. 가뭄·잔비·원작 메이커 등 기존 원작 이름은 유지합니다.

엇박자·알뜰주머니·기억비늘·여분쿠션·분위기타기·마지막한방울 6개 특성과 고정 타입 전용기 10개를 추가했습니다. 새 기술은 타입별로 복제하지 않으며 변화기는 참은숨·안전매듭 2개만 추가했습니다. 생성 결과에 배정되며 구체적 발동·초기화 규칙은 카드의 ‘적용 규칙’에서 확인합니다.

엇박자는 기술 분류나 능력치를 바꾸지 않습니다. 직전 기술과 물리·특수가 달라질 때만 피해를 1.25배로 합니다. 실전 설정의 ‘직전 기술 분류’로 비교할 수 있습니다. 여분쿠션은 한 번의 즉시 회복에서 최대 HP의 1/4 이상이 초과하면 HP 소모 없이 대타출동과 같은 대타를 만듭니다. 대타 HP도 최대 HP의 1/4이며, 기준과 대타 HP는 내림·최소 1입니다. 초과분은 누적하지 않고 이미 있는 대타를 교체·회복하지 않습니다.

거울우편과 봉합찌르기의 조건부 위력, 엇박자의 피해 보정은 결정력에 반영합니다. 여분쿠션의 대타 생성·도구 복원·PP 회복·표식·설치물 이동 등 턴 진행은 처리 규칙 데이터로 제공하며, 이 생성기에서 전투를 자동 진행하지는 않습니다.

날씨 생성 특성은 가뭄·잔비에 맞춰 등장 시 5턴입니다. 창작 날씨의 스피드 특성은 쓱쓱·엽록소·모래헤치기·눈치우기와 같은 스피드 2배를 적용합니다. 독가스·뇌우 전용 수혜 특성만 모래헤치기에 맞춰 해당 날씨의 턴 종료 피해를 면제하며, 금지 기술 실패 피해는 면제하지 않습니다. 추가 공격 강화·회복·피해 감소는 붙이지 않습니다. 실전 설정의 ‘날씨 효과 무효’ 조건은 이 보정과 날씨 화력을 함께 끕니다. 이는 원작 수치를 기준으로 맞춘 규칙이며 대전 승률 검증은 아닙니다.

- 투웨이는 같은 타입의 물리 1타·특수 1타입니다. 이원은 서로 다른 타입의 물리 2타 또는 특수 2타입니다.
- 기술 강화 특성에는 적용 대상 기술을 최소 2개 배정합니다. 조건부 특성은 조건 성립 시 적용 가능한 기술을 뜻합니다.
- 투웨이 특성은 복합 타입 쌍두에만 배정하며, 자신의 두 타입 투웨이 공격을 하나씩 받습니다.
- 스킨은 자신의 타입과 무관하게 배정됩니다. 노말 공격 2개를 보장하며 쌍두 스킨에는 노말 투웨이를 포함합니다.

- [전체 목록](NEW_CONTENT.md): 창작 특성·고정 랭업기·회복 및 방어 전용기·공격기·날씨·필드·공간 변화을 구분하고 원작 기반 항목을 별도로 수록합니다.
- [CSV](content-catalog.csv): 엑셀에서 출처·타입·분류별로 필터링할 수 있습니다.
- [JSON](content-catalog.json): 타격별 판정, 환경 연계, 부가효과, 랭업 페널티를 포함한 전체 데이터입니다.
- 창작 랭업기는 맞불각오·쇳심다지기 2개만 유지합니다. 두 기술은 최대 HP의 절반을 소모하고 다른 능력치를 2단계 내립니다. 원작 기반 랭업기 16개는 유지합니다. 작은 부가효과만 붙인 회복·방어 파생은 제거했습니다.

## 능력치 분배

| 능력치 | 기본 중간점 | 범위 | c 아래 / 위 |
|---|---:|---:|---:|
| HP | 90 | 40–140 | 0.10 / 0.50 |
| 공격 | 100 | 50–150 | 0.50 |
| 방어 | 100 | 40–160 | 0.10 / 0.50 |
| 특공 | 90 | 30–150 | 0.50 |
| 특방 | 80 | 10–150 | 0.10 / 0.50 |
| 스피드 | 80 | 10–150 | 0.85 |

1. 미배정 능력치 중 하나를 균등 추첨합니다.
2. 남은 종족값을 R, 나머지 능력치들의 최소 합을 L, 최대 합을 U로 둡니다.
3. 현재 능력치의 가능 범위는 `x = max(기본 최솟값, R−U)`, `y = min(기본 최댓값, R−L)`입니다. 추가 공통 제한을 켜면 기본 범위와 먼저 교차합니다.
4. 실제 중간점을 `M=(x+y)/2`로 갱신합니다. 따라서 총합 제약에 따라 기본 중간점에서 이동할 수 있습니다.
5. 시드에서 만든 `R₁,R₂,R₃ ∈ [0,10)`으로 다음 값을 계산하고 가장 가까운 정수로 반올림합니다.

`M + [(1+2c)(R₁−5) + (1−c)(R₂+R₃−10)] / 15 × (y−M)`

HP·방어·특방은 조정 중간점 M의 아래·위 방향을 별도 시드 난수로 50:50 선택합니다. 아래는 c=0.1, 위는 c=0.5로 난수 3개를 계산하고, 방향이 반대이면 세 난수를 각각 10−Rᵢ로 반사하여 선택한 반쪽 분포를 만듭니다. 기록의 난수는 반사 후의 실제 수식 입력([0,10])입니다. 방향은 반올림 전 값 기준입니다.

마지막 능력치는 추첨 없이 남은 값을 받으며 c는 적용하지 않습니다. 각 단계에서 남은 능력치들의 범위를 확보하므로 항상 합계 530이 되며 개별 범위를 벗어나지 않습니다. 내부 계산은 전체 정밀도를 사용하고 화면에만 난수를 소수 4자리로 줄여 표시합니다.

c=0은 세 난수의 합으로 중앙에 집중되고, c=1은 첫 난수만 사용해 조정된 범위에서 평탄해집니다. 총합 제약과 마지막 잔여 배정 때문에 최종 주변 분포는 원래 식의 분포와 달라질 수 있습니다.

## Firebase Hosting

프로젝트: `starter-forge-oflo`

배포 주소: https://starter-forge-oflo.web.app

창작 환경 10개에 원작 환경 16개를 더해 날씨 10개, 필드 8개, 공간 변화 4개, 설치물 4개를 사용합니다. 날씨·필드·룸은 기본 5턴, 설치물은 제거 전까지 유지됩니다. 날씨와 필드는 각각 하나씩, 룸과 설치물은 종류별로 공존합니다.

원작 날씨는 강한 햇살·비·모래바람·눈·구세대 싸라기눈, 원작 필드는 일렉트릭필드·그래스필드·미스트필드·사이코필드입니다. 원작 룸은 트릭룸·매직룸·원더룸, 설치물은 압정뿌리기·독압정·스텔스록·끈적끈적네트입니다. 눈과 싸라기눈은 서로 다른 날씨로 취급합니다.

대지의파동은 개미굴=벌레, 옥타곤=격투, 스왐프=땅 타입으로 바뀌고 위력이 2배가 됩니다. 화이트 페인트에서는 노말 타입입니다. 이 대응은 필드 설명과 실전 계산에도 반영합니다.

가뭄·잔비·엽록소·쓱쓱·일렉트릭메이커·독치장 등 원작 특성 25개와 원작 환경 관련 기술 33개를 추가했습니다. 환경 생성·활용·제거용 원작 기술은 `supportMoves`로 최대 2개를 별도 추천하며, 전용기 4칸에 섞지 않습니다. 필수 환경 생성 원작 기술은 이 추천에 먼저 배정합니다. 원작 이름·기본 수치는 `build_original_environments.py`가 PokeAPI CSV를 읽어 정적 파일로 저장합니다. 실행 중 네트워크는 사용하지 않습니다.

스왐프: 물·땅은 스피드 감소만 면제하며 기절 카운트는 받습니다. 턴 종료에 5에서 1씩, 비 계열인 뇌우에서는 2씩 감소합니다. 0이면 기절하며 영향을 벗어나면 초기화합니다.

`node environments.test.cjs`는 화이트 페인트 우선순위, 안개 명중·풀죽음, 독가스 금지·해제, 거꾸로 상성, 가변 연타, 스왐프 카운트, 원작 필드 접지 조건과 전장 특성별 생성 연계를 확인합니다. 현재 도구는 스타팅 생성기이며 전체 턴제 전투 시뮬레이터는 포함하지 않습니다. 설치물 피해·룸의 턴 진행은 카탈로그 규칙으로 제공하며 실전 설정 계산기에서 시뮬레이션하지 않습니다.

`firebase deploy --only hosting --project starter-forge-oflo`로 빌드·목록 추출 후 배포합니다. `public/`에는 index.html과 공개 콘텐츠 목록 3개만 복사합니다.

전용기 4칸에는 창작·타입 확장 기술만 배정합니다. HP회복·방어·흑안개·칼춤 등 원작 범용 기술은 도감 참고 항목으로 유지하고, 원작 환경 기술은 별도 추천합니다. 랭업 추천도 고정 타입의 창작 2개에서 선택하며, 회복 후보에는 씻어내기와 쉼표고치를 사용합니다.

방어 기반 공격은 방어 종족값이 100 이상이면서 공격 이상일 때, 특방 기반 공격은 특방 종족값이 100 이상이면서 특공 이상일 때만 배정합니다. 딱딱파워는 사용 가능한 신규 방어·특방 공격이 2개 이상일 때만 후보가 됩니다. 빈틈노리기에는 대상의 방어·특방을 낮추는 부가효과가 있는 기술을 최소 2개 연결합니다. 급소율 상승은 이 조건에 포함하지 않습니다.

창작 스킨은 블레이즈·아쿠아·리프·베놈·샌드·마인드·인섹트·스톤·팬텀·와이번·나이트·메탈 등 관련 영어 단어를 사용합니다. 원작 특성의 기존 이름은 유지합니다.

자기 타입과 겹치지 않는 스킨은 이전 대비 상대 가중치를 1/10로 낮춥니다. 단일·복합 타입 모두 적용하며, 자기 타입 스킨과 나머지 특성 사이의 상대 가중치는 유지합니다. 실제 당첨 확률은 형태별 전체 후보에 따라 달라집니다.

투웨이 기술명은 타입별 별칭 + 경정권입니다. 예: 화염경정권·수류경정권·철갑경정권. 이원 표기는 바위=석, 드래곤=앞자리 용·뒷자리 룡입니다.

이원 기술의 이름·타격 순서는 노말 → 페어리 → 에스퍼 → 불꽃 → 물 → 전기 → 풀 → 얼음 → 독 → 땅 → 비행 → 벌레 → 바위 → 고스트 → 악 → 강철 → 격투 → 드래곤으로 고정합니다. 입력 타입 순서를 뒤집어도 동일한 기술이 생성됩니다.

노말 펀치·노말 빔 2개만 도감과 생성 후보에서 제거했습니다. 다른 타입의 펀치·빔 34개는 유지합니다. 스킨·공격 강화 특성은 선공·흡수·급소·반동 등 효과가 있는 기술로 대상 2개를 확보합니다.

드레인펀치의 타입 확장형 17개는 별도 이름을 사용합니다. 예: 잿불주먹·물살훔치기. 원래 격투 타입 기술은 드레인펀치 이름을 유지합니다.

확정 급소·연타·선공·페널티 고위력 공격기 각 6종, 총 24종을 고정 타입으로 추가했습니다. 확정 급소기는 위력 70 이하·단타이며, 사용하는 공격/특공 종족값이 110 이하인 경우에만 배정합니다. 고위력기의 능력치 하락·반동·재사용 제한 등은 규칙 데이터이며 전투를 자동 진행하지 않습니다.

## 실전 설정 계산

물리 실내구도 = 최대 HP 실능치 × 적용 방어 ÷ 0.411, 특수 실내구도 = 최대 HP 실능치 × 적용 특방 ÷ 0.411입니다. 최종값만 반올림합니다. 도구·날씨의 능력치 보정은 반영하며, HP 비율을 바꿔도 최대 HP 기준을 유지합니다. 상성·급소·장막·조건부 피해 감소는 제외한 비교 지표로 실제 피해량은 아닙니다.

레벨은 50으로 고정합니다. 형태별 27개 분배에서 유효 EV 508을 추천하며, 해당 포켓몬이 진입한 후보 형태 사이의 분배도 선택할 수 있습니다. IV는 기본 31, 저속형 스피드는 0, 공격을 쓰는 타격이 없으면 공격은 0을 제안합니다. 방어·특방 기반 공격은 사용 능력치에 맞춰 투자를 조정합니다.

결정력은 위력 × 사용하는 실능치 × 자속 × 특성·도구·전장 보정의 타격별 합입니다. 스킨은 타격별 변환 후 자속을 다시 판정하며, 화이트 페인트에서는 스킨을 끕니다. 가변 연타는 최소·최대·기대값, 고정 연타는 타격 수와 개별 위력의 합계를 보여줍니다. 확정 급소는 1.5배를 반영하고 급소 방지 조건에서는 제외합니다. 명중률·상성·상대 내구·일반 급소 확률·피해 난수는 결정력에 포함하지 않습니다. 랭업은 적용하지 않고 0단계를 기준으로 합니다.

기본 수치는 성격까지 적용한 실능치, 적용값은 도구·전장에 따른 능력치 보정까지 반영합니다. 도구는 12가지(도구 없음 포함)를 제공하며, 변화기가 있으면 돌격조끼는 오류로 안내합니다. 추천은 고정 규칙이며 메타 상대를 대상으로 최적화한 분배가 아닙니다.
