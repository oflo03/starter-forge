# 팬 창작 기술·특성 도입 후보

조사일: 2026-10-28. 대상: Smogon Create-A-Pokémon(CAP), Pokémon Insurgence, Pokémon Uranium.

현재 메이커에 넣을 만한 발상을 추린 초기 조사 기록이다. 후속 선택으로 끈질긴손길·탄력붙이기·다시도는별·녹물세례를 채택하고, 별도 창작 특성 이른혜성을 추가했다. 나머지는 조사 후보로만 유지한다. 실제 적용 수치는 ../NEW_CONTENT.md의 v1.10.0 목록이 기준이다. 영문명과 원본 효과는 출처의 내용이며, **한국어 이름·조정안은 이 프로젝트용 제안**이다. 팬게임 위키는 해당 프로젝트의 규칙 설명 자료로 사용했고, 실행 코드를 검증한 것은 CAP 특성뿐이다.

## 중복·충돌로 우선순위를 낮춘 발상

- **Hubris:** 상대를 쓰러뜨리면 특공이 오르는 발상은 현재 원작 흑의울음과 겹친다. 별도 창작 특성보다 기존 이름을 쓰는 방향이 맞다. [Insurgence Hubris](https://wiki.p-insurgence.com/Hubris_(Ability))
- **Spirit Away:** 상대를 들어 올려 다음 턴 공격하는 형태는 프리폴과 유사해 신규성 우선순위가 낮다. [Insurgence Spirit Away](https://wiki.p-insurgence.com/Spirit_Away_(move))
- **New Moon:** 어두운 날씨 발상은 이미 있는 어두운 오라와 역할이 겹친다. 새 날씨 추가보다 기존 날씨의 기술·특성 연계를 보강한다. [Insurgence New Moon](https://wiki.p-insurgence.com/New_Moon_(weather))

현재 우선 검토할 특성은 **끈질긴손길·산넘기·되받아치기·탄력붙이기·녹여빚기**, 기술은 **허점콕·녹물세례·모아치기**다. **삼색프리즘**은 무작위 타입 전환의 확률과 스킨 처리 순서를 명시해 검토한다. 모두 채택 전 기존 목록과 효과 중복을 다시 대조하고, 강화 특성에는 강화받는 기술 2개 이상을 보장한다. 이 문서의 너프 수치는 설계 제안이며 실전 밸런스 검증 결과는 아니다.
